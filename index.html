01 / About

I build test harnesses for software that doesn't give the same answer twice.

I'm a Lead AI Test Automation Engineer with 14.5 years of software engineering experience, specialising in test harness architecture, non-deterministic system verification and Python-based automation framework development.

Most recently I tested AI models for Apple's internal employee website: an AI chatbot / help assistant and an AI employee performance assistant. I tested them manually, wrote the testing guidelines and test cases for the AI models, and automated GenAI testing with Python and Streamlit.

Right now I focus on AI assurance and evaluation: automated test suites that score LLM and agentic workflows on multi-turn state persistence, tool-calling accuracy, intent resolution and semantic assertions. I bring established software testing methods to new AI evaluation needs, turning system requirements and governance principles into reproducible, production-grade test pipelines.

Before AI, I spent over a decade on UI, API and performance automation for clients such as Amazon Audible, Overstock and athenahealth. I've led teams, mentored engineers and owned quality from requirements to release.
